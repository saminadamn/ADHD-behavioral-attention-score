# Questionnaire-derived validation results

_Generated by `backend/scripts/validate_against_assessment_questionnaire.py` on 2026-11-10._

## What this is

Ten classroom turns, each written to embody one construct from a standard 50-item clinical ADHD assessment (DSM-5-TR / ASRS-style inattention and hyperactivity-impulsivity items, Barkley BDEFS executive-function items), run through the full pipeline (`signal_extractor -> state_classifier -> reward_modeler -> bas_tracker -> intervention_generator`) as one continuous session, with BAS and attention-state memory carried across turns the way a real session would be.

## What this is not

**Not a validation study against the questionnaire.** The pipeline classifies one classroom turn (a teacher prompt, a student response, and the response latency) into Focused / Distracted / Impulsive -- it does not take a 50-item self-report, and a single turn cannot establish onset, cross-setting presence, or impairment, which is what an actual clinical assessment measures. These turns were constructed by hand to *embody* one construct each, specifically so any gap between what the construct implies and what the pipeline's five behavioral signals can see from text alone would show up as a mismatch -- see `docs/model_limitations.md` for three such gaps that were found and fixed this way.

## Reproduce this

```bash
cd backend
python scripts/validate_against_assessment_questionnaire.py
```

The same ten cases are also asserted as regression tests in `backend/tests/test_questionnaire_constructs.py` (`python -m pytest tests/test_questionnaire_constructs.py -v`), so a future change to the pipeline that breaks one of these constructs fails CI rather than silently drifting.
